# Pixra

An open-source, extensible web-based image editor.

## Features

- Basic image editing: crop, resize, brush, marquee selection
- Multi-tab support
- Undo/redo history
- Export to PNG, JPEG, WEBP
- Plugin system for custom tools

## Getting Started

```bash
pnpm install
pnpm dev
```
