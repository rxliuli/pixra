Pixra is a web-based image editor that runs entirely in your browser. No installation required.

## Opening an Image

1. Click **File > Open** or use the keyboard shortcut `Ctrl+O` (Windows/Linux) or `Cmd+O` (macOS)
2. Select an image file from your computer
3. The image will open in a new tab

You can also create a new blank image via **File > New**.

## Basic Editing

### Undo/Redo

- **Undo**: `Ctrl+Z` / `Cmd+Z`
- **Redo**: `Ctrl+Shift+Z` / `Cmd+Shift+Z`

### Copy/Paste

- **Cut**: `Ctrl+X` / `Cmd+X`
- **Copy**: `Ctrl+C` / `Cmd+C`
- **Paste**: `Ctrl+V` / `Cmd+V`

### Zoom

- **Zoom In**: `Ctrl+=` / `Cmd+=`
- **Zoom Out**: `Ctrl+-` / `Cmd+-`
- **Reset Zoom**: `Ctrl+0` / `Cmd+0`

## Saving Your Work

### Save

Click **File > Save** or press `Ctrl+S` / `Cmd+S` to save the current image.

### Export

Click **File > Export** to export your image in different formats:

- PNG
- JPEG
- WebP

## Using the Command Palette

Press `Ctrl+Shift+P` / `Cmd+Shift+P` to open the command palette. This gives you quick access to all available commands, including plugin commands.
